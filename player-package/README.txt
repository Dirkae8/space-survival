ПЕРИГЕЛИЙ — автономная браузерная сборка

ЗАПУСК
1. Распакуйте весь ZIP в отдельную папку.
2. Windows: дважды щёлкните start-game.bat.
   macOS / Linux: запустите start-game.sh.
3. В браузере откроется локальная страница игры. Оставьте окно терминала открытым, пока играете; закройте его или нажмите Ctrl+C, чтобы остановить сервер.

Игра полностью содержится в этой папке и после распаковки не требует скачивания файлов из интернета. Для локального запуска нужен Python 3; в Windows-версии есть резервный запуск через встроенный PowerShell. Если браузер не открылся автоматически, адрес игры будет показан в окне запуска.

УПРАВЛЕНИЕ
W A S D — ходьба; мышь — обзор; Shift — бег; Space — прыжок; E — подобрать объект; R — сканер; F — ремонт; Esc — пауза и освобождение курсора.

Это браузерная игра: используйте современный Chrome, Edge или Firefox с поддержкой WebGL. Прогресс сохраняется в локальном хранилище браузера и привязан к используемому профилю.
