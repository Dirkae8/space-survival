# ПЕРИГЕЛИЙ — космическое выживание

Браузерный first-person прототип на Vite и Three.js. Экспедиция начинается в Солнечной системе: карта содержит восемь планет, Луну, карликовые планеты и крупные спутники. У газовых гигантов нет выдуманной твёрдой поверхности — для высадки выбираются их спутники.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`.

## Игровой цикл

- Выбери реальное тело Солнечной системы и высадись на доступный для посадки мир.
- Исследуй процедурный участок поверхности от первого лица. Рельеф, камни и текстуры создаются локально; геология зависит от выбранного тела.
- Сканируй местность (**R**), подходи к отмеченным залежам и забирай ресурсы (**E**).
- Собери **3 Fe и 2 Si**, чтобы восстановить посадочный модуль. Лёд (**H₂O**) можно переработать в кислород; заряд сканера и состояние скафандра требуют внимания.
- Поднимись на орбиту, выбери следующий объект или вернись на поверхность. Прогресс сохраняется локально.

**Управление:** WASD — движение, мышь — обзор, Shift — ускоренное движение, Space — прыжок, E — взаимодействие, R — сканер, F — ремонт, Esc — пауза и освобождение курсора. На телефоне доступны сенсорные кнопки.

Каталог включает отдельные карточки для известных экзосистем Проксимы Центавра, TRAPPIST-1 и Kepler-186. Измеренные периоды, радиусы и массы отделены от оценочных характеристик; там, где свойства атмосферы или поверхности не установлены, высадка прямо обозначена как модельная визуализация. Кнопка **«Синтез»** создаёт воспроизводимый сектор: тип звезды, интервалы орбит, масса и радиус планет, ускорение свободного падения, альбедо, равновесная температура и примерные классы атмосфер согласуются простой физической моделью. Синтетические объекты помечены отдельно и не выдаются за реальные наблюдения. Данные округлены; температура и давление служат игровыми ориентирами, а не полноценной климатической симуляцией.

Это основа для дальнейшего развития, а не готовая игра уровня Unreal Engine: в браузерной версии уже есть реальная карта Солнечной системы, first-person управление, локальная генерация миров, процедурные текстуры и поверхность, добыча ресурсов, система выживания и переходы между орбитой и высадкой.
